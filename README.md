Esse foi meu primeiro Dashboard e nele foi feito a limpeza e tratamentos dos dados e em seguida um dashboard para melhor visualização dos KPIs e tomada de decisões.

# 👗 Dashboard de Avaliações de Roupas Femininas

Este projeto foi desenvolvido foi feito com Google Sheets e Poer BI e  com o objetivo de analisar avaliações de clientes sobre roupas femininas. A partir dos dados coletados, foi criado um dashboard interativo no Power BI que apresenta informações relevantes sobre a satisfação dos consumidores, pontos fortes e oportunidades de melhoria nos produtos.

## 🔍 Principais insights

- Compras por idade
- Porcentagem de avaliações por estrela
- Recomendações
- Roupas mais vendidas
